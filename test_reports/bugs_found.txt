  - VotingHandler.vote() is triggered unnecessarily
  - 30-second timeout occurs during specialist voting
  - Query fails with TimeoutError

  2. Add negative keywords to law domain: NOT ['newton', 'physics', 'first law']
  3. Increase minimum keyword confidence threshold
  4. Check if matched domain keywords appear in context that suggests different domain
